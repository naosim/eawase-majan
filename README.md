# 絵合わせマージャン

PHP 8.3、SQLite、Vanilla JavaScriptで動く2〜4人用ブラウザゲームです。ポーリングでルーム状態を同期し、手牌はプレイヤーごとのUUIDを鍵として暗号化した状態で配信します。

## WSLで起動

PHP 8.3とSQLite拡張をインストール済みなら、プロジェクトのルートで起動します。

```bash
./start.sh
```

Windowsのブラウザで <http://localhost:8000> を開きます。WSLのlocalhost転送が利用できない場合は、WSLで `hostname -I` を実行し、表示されたIPアドレスを使って `http://<WSLのIP>:8000` を開いてください。

Ubuntu 22.04でPHPを新規導入する場合は、PHP PPAを登録します。

```bash
sudo add-apt-repository ppa:ondrej/php
sudo apt update
sudo apt install php8.3-cli php8.3-sqlite3
```

`apt update` が別の外部リポジトリのエラーで失敗する場合は、その古いリポジトリ設定を確認してから再実行してください。このWSLでは既存のNodeSource設定が404を返しました。今回のPHP導入ではその設定を変更していません。

環境状態のJSONは <http://localhost:8000/health.php> で確認できます。DBは初回のヘルスチェックまたはAPIアクセス時に `data/donjara.db` へ自動作成されます。必要なら `php db_init.php` で明示的に初期化できます。停止するには起動したターミナルで `Ctrl+C` を押します。

このPHPビルトインサーバーは開発専用です。インターネットに公開しないでください。

## さくらのレンタルサーバーへのデプロイ

GitHub Actionsのデプロイは `public/` の中身をFTPの `FTP_SERVER_DIR` 直下に配置し、PHP補助ファイルを `_app/` に配置します。`FTP_SERVER_DIR` を公開したい `/donjara/` ディレクトリに設定すると、`https://<ドメイン>/donjara/` で開けます。HTML・API・CSS・対局状態ファイルはサブディレクトリからの相対パスで参照します。

SQLite DBは公開ディレクトリの親に作成します。PHP実行ユーザーがその親ディレクトリに書き込めることと、PHP 8.3およびPDO SQLiteが有効であることが必要です。デプロイ後は `https://<ドメイン>/donjara/health.php` が `status: ok` を返すか確認してください。

## 遊び方

1. プレイヤー名を入力してルームを作成します。
2. 表示された招待リンクをほかのプレイヤーに共有します。2〜4人で遊べます。
3. 作成者が「対局開始」を押します。
4. 自分のターンに牌を引き、牌を捨てます。捨てるときにテンパイしていればリーチを宣言できます。リーチ後はツモ牌だけを捨てられます。
5. リーチ中に9枚の牌で同じ絵柄3枚組を3セット作ると、ツモまたはロンで上がれます。オールマイティ牌2枚は任意の絵柄の代わりになります。
6. 次のプレイヤーは直前の捨て牌を使える場合にポンできます。ロン確認は対象プレイヤーが応答するか、20秒でタイムアウトします。

捨て牌は卓上でプレイヤーごとの列に分けて表示されます。各列の名前・席番号と牌の並びで、誰が何を捨てたか確認できます。

手番の制限時間は30秒です。期限切れ後、接続中のブラウザがPHP APIにタイムアウト処理を依頼し、自動ツモ切りまたは自動パスを行います。リロードや再接続では同じブラウザのUUIDを使ってルームに戻れます。

リーチ時に1,000点を供託し、上がったプレイヤーが供託点を受け取ります。ほかのプレイヤー間の点数移動は行いません。

## スキン

「スキンエディタ」からスプライトシート画像と牌の切り出し座標を設定し、JSONを書き出せます。ゲーム画面の「スキン読込」でそのJSONを読み込むと、以後そのブラウザで使われます。既定の牌IDは `A1`〜`C3` と `J1`〜`J2` です。エディタは完全にクライアント内で動き、画像をサーバーへ送信しません。

## データと実装

- `db_init.php` — SQLiteスキーマ初期化
- `game.php` / `public/action.php` — ルーム・ターン・勝敗・タイムアウトのサーバー処理
- `public/index.html` — ゲーム画面と2秒間隔の状態ポーリング
- `public/editor.html` — 静的スキンエディタ
- `data/donjara.db` — ルームとプレイヤーの状態
- `public/data/room_*.json` — クライアント向け状態ファイル。各手牌はAES-128-CBCで暗号化

ブラウザ標準のWeb Crypto APIを使用するため、CryptoJSなどのCDN依存はありません。

## テスト

```bash
php tests/game_rules.php
tests/integration.sh
tests/deployment_layout.sh
```

統合テストは一時SQLite DBと一時HTTPサーバーを使用し、ルーム作成、暗号化、ツモ、タイムアウト、リーチ、ロン、サブディレクトリへのデプロイ構成を検証します。
